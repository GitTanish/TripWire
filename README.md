# Tripwire

I'm exploring how to make agent execution more reliable.

Tripwire is a small circuit-breaker prototype for agentic workflows. I'm starting with execution limits, tool-call budgets, timeouts, and loop detection, then testing how they behave under failure.

The goal is to understand the design trade-offs before bringing these mechanisms into a larger agent runtime.

Python, deterministic tests, and a few focused experiments.

Work in progress.
